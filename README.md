# 🧠 Neuro-biz-aiy — Бизнес-ИИ для интервью и обучения

**Python** · **License: MIT**

Neuro-biz-aiy — это локальная программа для сбора бизнес-интервью и дообучения текстовой ИИ-модели на основе опыта руководителя или владельца бизнеса. Создайте персонального AI-ассистента, который отвечает в стиле эксперта!

---

## 🚀 Возможности

- ✅ **Интервью с руководителем** — 10+ готовых вопросов, можно редактировать.
- ✅ **Редактирование вопросов** — добавляйте, удаляйте, изменяйте вопросы в реальном времени.
- ✅ **Экспорт данных** — сохраняйте ответы в CSV и PDF.
- ✅ **Дообучение модели (QLoRA)** — используйте локальный датасет для обучения.
- ✅ **Чат с обученной моделью** — задавайте вопросы и получайте ответы в стиле эксперта.
- ✅ **Веб-интерфейс (Streamlit)** — красивый и удобный интерфейс в браузере.
- ✅ **Классический интерфейс (Tkinter)** — для тех, кто предпочитает десктопные приложения.

## 📦 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/nemo94314-hub/neuro-biz-ai.git
cd neuro-biz-ai
pip install -r requirements.txt
pip install -e .
streamlit run app.py
python gui_tk.py

Если команда pip не работает
Замените pip на python -m pip во всех командах. Например:

python -m pip install -r requirements.txt
python -m pip install -e .
Если streamlit не запускается
bash
python -m pip install streamlit pandas reportlab

## 🤖 Telegram-бот

У нашего продукта есть Telegram-бот для автоматических продаж и поддержки клиентов.

**Что умеет бот:**
- Отвечает на вопросы о продукте
- Даёт ссылку на скачивание
- Помогает с покупкой лицензии

**Как попробовать:**
👉 [@NeuroBiAIbot](https://t.me/NeuroBiAIbot)

**Команды бота:**
- `/start` — приветствие и ссылка на скачивание
- `/buy` — информация о покупке лицензии
- `/help` — список команд

**Для разработчиков:**
Код бота находится в файле `bot.py`. Чтобы запустить локально:
```bash
pip install pyTelegramBotAPI
python bot.py
